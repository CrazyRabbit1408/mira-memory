# Кумар — память и диалог через OrcaRouter API

Версия 0.14.0-orcarouter. Эта сборка запускает панель, память и backstage-управление на компьютере, а ответы Кумара получает через **OrcaRouter API**. Ollama и локальная LLM полностью отключены. TTS пока остаётся текстовой заглушкой.

## Быстрый запуск в WSL

> Команды ниже выполняются внутри WSL. Не вводите `wsl` уже находясь в WSL.

```bash
cd /home/kymar_x_ai/mira-memory-v1
cp .env.example .env
nano .env
```

В `.env` добавьте свой ключ, не публикуйте его и не включайте `.env` в архив:

```dotenv
ORCAROUTER_API_KEY=вставьте_актуальный_ключ_сюда
ORCAROUTER_BASE_URL=https://api.orcarouter.ai/v1
ORCAROUTER_SESSION_ID=kumar-panel
KUMAR_SEMANTIC_SEARCH=0
```

Затем:

```bash
chmod +x launcher/run-mira.sh
./launcher/run-mira.sh prepare
./launcher/run-mira.sh start
```

Откройте **http://127.0.0.1:8000**. Для остановки:

```bash
./launcher/run-mira.sh stop
```

Если проект лежит в Windows Downloads, путь из WSL выглядит примерно так:
`/mnt/c/Users/<имя>/Downloads/<архив>`. Команда `C:\Users\...` сама по себе не является командой Linux.

## Настройки диалога

По умолчанию выбрана `deepseek/deepseek-v4.1-flash-free`. В панели доступны:

- `deepseek/deepseek-v4.1-flash-free` — бесплатный режим для тестов;
- `tencent/hy4-preview-free` — бесплатный режим с отдельными лимитами OrcaRouter;
- `deepseek/deepseek-v4.1-flash` — платная модель, можно включить позже.

Системный характер Кумара хранится в промпте OrcaRouter (`kumar-live`, версия `latest`), а эта панель передаёт динамику: историю, найденные фрагменты памяти, эмоцию и вопрос зрителя. Ключ никогда не показывается API панели и не входит в резервные копии.

Кнопка **«Перезапустить LLM»** теперь сбрасывает runtime-сессию OrcaRouter. Она не пытается остановить локальную модель, потому что локальной модели в этой сборке нет. Кнопки остановки и возобновления TTS оставлены для будущего настоящего TTS.

## Память

SQLite, разрешённый лор, граф связей и фрагменты текущего эфира работают локально. На этом этапе смысловой поиск и embeddings отключены вместе с Ollama: поиск выполняется по словам. Файлы лора добавляются в `config/lore/character`, а backstage-фрагменты можно внедрять прямо во время эфира.

## Диагностика

```bash
./launcher/run-mira.sh status
./launcher/run-mira.sh diagnostic
./launcher/run-mira.sh start-attached
```

`start-attached` оставляет журнал в текущем окне WSL. Обычный `start` пишет журнал в `launcher.log`. Если API-ключ не задан, панель откроется, но запрос чата покажет понятную ошибку вместо падения приложения.

## Безопасность

- Никогда не отправляйте API-ключ в чат, репозиторий или архив проекта.
- Ключ, который уже публиковался в переписке, лучше отозвать в OrcaRouter.
- Не открывайте локальную админ-панель в интернет: имя зрителя не является аутентификацией.
- Не добавляйте в память пароли, токены, адреса и лишние персональные данные.
- `data/`, `.env` и логи исключены из поставочного архива.

## Тесты

```bash
uv run python -m pytest -q
```

Тестовый режим используется только в автоматических тестах; в обычном запуске конфигурация — OrcaRouter API.
