=====================================================================
  MIRA / KUMAR  —  запуск в Windows
  Версия 0.14.0-orcarouter
=====================================================================

Это сборка «Кумар» (память + диалог через OrcaRouter API).
Панель работает локально на компьютере, ответы приходят из
облачного OrcaRouter API. Ollama и локальная модель отключены,
поиск по памяти работает по словам, TTS пока пишет текст в файл
без звука.


---------------------------------------------------------------------
1. ЧТО НУЖНО ОДИН РАЗ
---------------------------------------------------------------------

- Установленный Python версии 3.10–3.13.
  Скачать: https://www.python.org/downloads/
  ВАЖНО: при установке поставьте галочку
  «Add python.exe to PATH», иначе скрипты не найдут Python.

- Подключение к интернету (для установки зависимостей и для
  запросов к OrcaRouter API).

Больше ничего устанавливать не нужно. WSL и Linux не требуются.


---------------------------------------------------------------------
2. ПЕРВОНАЧАЛЬНАЯ ПОДГОТОВКА
---------------------------------------------------------------------

1. Откройте папку проекта:
   C:\mira-memory-v0.14.0-orcarouter\mira-memory-v1

2. Дважды щёлкните по файлу SETUP_MIRA.bat

   Скрипт:
   - проверит Python;
   - создаст виртуальное окружение .venv;
   - установит только отсутствующие зависимости;
   - создаст файл .env из .env.example, если его ещё нет.

   Установка может занять несколько минут — это нормально.


---------------------------------------------------------------------
3. API-КЛЮЧ ORCAROUTER
---------------------------------------------------------------------

Чтобы чат отвечал, нужен ключ OrcaRouter:

1. Откройте файл .env в папке проекта (Блокнот или любой
   текстовый редактор).
2. Найдите строку:
       ORCAROUTER_API_KEY=
3. Вставьте свой ключ сразу после знака «=», например:
       ORCAROUTER_API_KEY=ваш_ключ_здесь
4. Сохраните файл.

Без ключа панель откроется, но чат будет показывать понятную
ошибку вместо ответа. Ключ хранится только в .env и не
попадает в резервные копии и архивы. Не передавайте ключ
посторонним.


---------------------------------------------------------------------
4. ЗАПУСК
---------------------------------------------------------------------

Дважды щёлкните по файлу START_MIRA.bat

Скрипт сам:
- проверит окружение и зависимости;
- при первом запуске выполнит подготовку автоматически;
- запустит панель в фоне;
- дождётся готовности и откроет браузер.

Панель доступна по адресу:
       http://127.0.0.1:8000

Окно запуска можно закрыть — панель продолжит работать в фоне.
Журнал работы сохраняется в файл launcher.log в папке проекта.


---------------------------------------------------------------------
5. ОСТАНОВКА
---------------------------------------------------------------------

Дважды щёлкните по файлу STOP_MIRA.bat

Скрипт корректно завершит процесс панели по сохранённому PID.
После остановки панель станет недоступна по адресу
http://127.0.0.1:8000


---------------------------------------------------------------------
6. ПОВТОРНЫЙ ЗАПУСК
---------------------------------------------------------------------

Повторный запуск НЕ переустанавливает зависимости.
Окружение и установленные пакеты сохраняются в папке .venv.
Просто снова запустите START_MIRA.bat.


---------------------------------------------------------------------
7. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
---------------------------------------------------------------------

- Окно закрывается сразу или пишет «Python не найден»
  → установите Python и включите «Add python.exe to PATH»,
    затем снова запустите SETUP_MIRA.bat.

- «Не удалось установить зависимости»
  → проверьте интернет и повторите SETUP_MIRA.bat.
    Подробности ищите в файле launcher.log.

- Панель запустилась, но чат отвечает ошибкой
  → скорее всего, не задан или неверен ORCAROUTER_API_KEY в .env.

- Панель не открылась в браузере автоматически
  → откройте вручную: http://127.0.0.1:8000

- STOP_MIRA.bat пишет, что процесс не найден
  → значит, панель уже остановлена; это не ошибка.

- «Панель не ответила за 30 секунд»
  → посмотрите последние строки launcher.log, там указана причина.


---------------------------------------------------------------------
8. ЧТО ЭТО ЗА СБОРКА (ОГРАНИЧЕНИЯ)
---------------------------------------------------------------------

- Ответы приходят из OrcaRouter API. Бесплатные лимиты и
  доступность моделей определяет OrcaRouter.
- Ollama и смысловой поиск (embeddings) отключены. Поиск по
  памяти работает по словам.
- TTS — текстовый: последняя фраза пишется в
  data/last_tts.txt, звука нет.
- Twitch и чат-платформа не подключены.


---------------------------------------------------------------------
9. БЕЗОПАСНОСТЬ
---------------------------------------------------------------------

- Не публикуйте .env и не вкладывайте ключ в архивы.
- Не открывайте локальную панель в интернет: имя зрителя не
  является защитой.
- Не добавляйте в память пароли, токены и лишние персональные
  данные.


---------------------------------------------------------------------
10. ФАЙЛЫ ЗАПУСКА
---------------------------------------------------------------------

  SETUP_MIRA.bat     — первоначальная подготовка (один раз)
  START_MIRA.bat     — запуск панели (двойной щелчок)
  STOP_MIRA.bat      — остановка панели
  README_WINDOWS.txt — эта инструкция

  .venv\             — виртуальное окружение Python
  .env               — ваш локальный ключ и настройки (не в архиве)
  launcher.log       — журнал работы панели
  .mira-app.pid      — служебный файл с PID процесса
