# Memory foundation v0.7

## Доработки без запуска тестового набора

- Убран глобальный запрет на любые цифры при извлечении кандидатов памяти.
  Обычные фразы вроде «мне 27 лет» или «у меня 3 кошки» больше не
  отбрасываются только из-за числа.
- Отдельно блокируются длинные числовые последовательности, похожие на
  телефон, номер карты или другой идентификатор.
- Добавлены проверки ссылок, email, паролей, токенов, адресов и чувствительных
  тем.
- Расширены безопасные шаблоны кандидатов: «мне нравится», «я предпочитаю»,
  «у меня есть», «я работаю», «я живу», «меня зовут».
- Граф теперь распознаёт короткие имена вроде «Лида» и базовые русские
  окончания, вместо прежнего жёсткого порога в пять символов.
- Обновлены ожидаемые тестовые сценарии, но сам тестовый набор по просьбе
  владельца пока не запускался.

## Следующий блок

Следующим этапом остаются консолидация длинных разговоров, полноценные
конфликты и временные состояния памяти, а затем отдельный runtime для голоса.
