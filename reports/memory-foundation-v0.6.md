# Memory foundation v0.6

## Что изменено

- Заметки памяти получили тип: `fact`, `preference`, `relationship`, `event`,
  `promise`, `open_thread`, `belief` или `canon`.
- Для заметок добавлены важность, уверенность, источник и история ревизий.
- Старые базы мигрируются при запуске: существующие записи получают безопасные
  значения по умолчанию.
- Тип и важность доступны в панели при добавлении и редактировании заметки.
- При сборке контекста тип, важность и уверенность передаются локальной модели.
- При ранжировании контекста сначала учитываются разрешённые канонические и
  структурированные источники, затем важность записи.
- Тестовая Мира считает себя человеком, отвечает на языке последнего сообщения,
  различает факт, догадку, слова собеседника и изменение мнения. Эти правила
  пока являются профилем персонажа; планировщик инициативных реплик и
  языковой runtime ещё не подключены.

## Проверки

- `python3 -m compileall -q src tests` — пройдено.
- `node --check src/static/app.js` — пройдено.
- Полный `pytest` в среде сборки не запускался: в ней отсутствуют `uv` и
  `pytest`. В проект добавлены тесты для типов памяти, важности и ревизий;
  они должны запускаться у пользователя через `uv run pytest -q`.

## Ограничения

Это всё ещё ядро памяти, а не готовый стример. В нём пока нет настоящих STT,
TTS, streaming-ответов, OBS, Twitch и планировщика автономных реплик.
