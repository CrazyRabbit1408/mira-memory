# Авторский архив

Эта папка предназначена для авторских черновиков, которых персонаж не должен знать. Файлы здесь не включаются в поиск и запросы к модели. Не помещайте их в `config/character.md`, разрешённый лор, заметки или чат. Не публикуйте резервные копии с личными данными и авторскими секретами.
